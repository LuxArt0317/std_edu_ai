# Stitch UI Prompts

Project: `projects/16353832066758496067`  
Design system: `assets/dfc4619bb6af499394c5c7afed65bcda`  
Model: Gemini 3.1 Pro, desktop

These prompts deliberately specify workflows and controls. Stitch output is accepted only after the generated HTML is compared with `needed.md` and the real role-authorized operations.

## Teacher Course Studio

Design an STU Nexus course workspace with a course selector, breadcrumb, clickable module rows, nested lessons/materials, and visible Add Module. Every module needs Open, Add lesson/material, Edit, Publish/unpublish, Reorder, and More. Opening a lesson needs multi-page Tiptap editing, images, files/links, preview, save draft, publish, duplicate, reorder, and archive. Assessments need Create, Open, Edit, Questions, Preview, Publish, Results, and Grade submissions. Include announcements, attendance, and schedule shortcuts. Never use passive text where a user expects an action.

## Student Learning Path

Design an STU Nexus learning path with expandable module rows and real clickable lessons showing type, duration, completion, and active state. The rich multi-page reader needs previous/next page, contents, mark complete, bookmark, permitted downloads, Ask Nexus about this lesson, and Next lesson. Separate assessments with availability, attempts, deadlines, result-release status, and prior results; never include AI answer or submission actions.

## People & Roles

Design an Owner/Administrator directory with search and filters, clickable account rows, Add Account, and Bulk Import. The account detail needs identity editing; role, department, program, class, and advisee assignments; invitation/resend; credential rotation; session revocation; suspend/archive/restore; and immutable history. Protect the Owner and require reasoned confirmation for mutations.

## Admissions and Student Success

Design a workflow-first applicant pipeline and detail view with Add/Edit, stage changes, interactions, tasks, assignment, admit/reject, and Registrar handoff. Campaigns need Create/Edit, recipient preview, Approve & Send, pause/archive, and delivery evidence. Cases need Open/Edit, assignment, priority/status, interactions, reasoned sensitive access, resolve/close/archive, and activity history.
