# Local chatbot answer strategy review

25 November 2026. Related: #100, #101, #102. No push, deployment, database migration or student-record creation. The local API uses its configured online model/data services.

## Evidence and method

Reviewed all 53 locally saved Answer Lab questions/references and the 25 saved runs; fresh trial agents never received the expected answers. All 50 unique local destinations in the references have an existing captured page/file or native service route family. This is a route/source audit, not proof that every authenticated workflow has working data. Native routes still require their exact authorized records.

Three fresh agents ran with context inheritance disabled. They received only public raw directory/app metadata and neutral task packets. Trial 1 used the old public composition core; trial 2 used task-aware guidance and local destinations with the same four questions/evidence. Trial 3 used held-out Moodle metadata and authorization/action scenarios with the same strategy in independently worded instructions. Agent model/settings were not exposed. These trials do not measure this application's selected provider, full retrieval graph, or statistical accuracy.

## Observations and changes

- Baseline trial selected external services because the old prompt explicitly required official URLs. The candidate selected supplied local equivalents. Updated public, private and corrective composition to share task-level guidance; removed the conflicting external-only instruction.
- Actual directory routing treated a friend's grades as a generic grade lookup. Added an authorization explanation before that shortcut, including in the authenticated API after session verification. No private data is queried to answer this permission question.
- Generic scholarship keyword matching returned a student-aid service list instead of answering requirements. Directory fallbacks now require a navigation/list intent; substantive policy questions continue into source retrieval.
- Moodle login had no directory answer. Added navigation grounded in the real DTM route, Continue with Google control and shared session code. Combined School Affairs/DTM grade directions retain both destinations; personal marks remain caller-scoped.
- The shared language detector and directory responses now preserve English surrounding an isolated Chinese interface label.
- Local page evidence previously loaded public captures from production. The local runner now supplies a loopback-only source origin; production and invalid origins retain the production origin. Checksums and exact manifest paths remain required.
- Imported the missing 37-page IPIAC 115-entry source draft, unchanged PDF and searchable HTML, at /source-documents/ipiac-115/index.html. Source SHA-256: 0bf1a3ae04f86dcad8d9dc0df9534249957f5d16cfa7a49b817a6f7049ffcdd1. Query-selected raw physical-page excerpts can enter the existing evidence composition and independent-verification path. Draft/cohort scope and truncation remain explicit. The expected FAQ prose is never imported into runtime.
- The exact payment-method page returned HTTP 403. No invented replacement procedure was created. Existing related payment pages remain available; the exact content gap remains #102.

## Trial outcomes and limits

Baseline and candidate both acknowledged missing timetable evidence rather than inventing classes. Candidate trials used local links, retained supported repair navigation, separated the two grade collections, and did not invent third-party permissions or appointment receipts. The fuller reference's leave procedure and actual student timetable could not be reproduced from directory metadata alone. Prompt changes cannot create missing records, current appointment availability, cohort rules or payment integration.

No pass percentage is claimed for the 53 questions. Direct directory matches changed from 15 to 9; a directory match is not a completeness score. Saved historical answers and expected references were not rewritten. Trial evidence is saved separately under the ignored local .evaluation-lab/prompt-trials/2026-11-25 directory.

## Local API observation

Moodle login, both grade destinations and third-party grade access returned grounded public guidance through the running API. The leave question initially hit a private-history shortcut; its form/page/section intent was corrected and the API then returned the form in English. One IPIAC requirements request reached composition and independent verification against the local source draft, returning a verified but incomplete answer because early excerpt limits omitted conditions later on the same pages. Relevant-page excerpts were expanded within a bounded source budget. The final request then returned the academic tiers (including both grade and rank conditions), housing exception, A2 and placement requirements with a local document citation; independent verification passed in one check. This is one real-provider question, not acceptance of all 53. Capture dates are presented in Asia/Manila; the earlier UTC-stamped trial response is retained unedited in its local evidence file. These observations are kept separately from user lab runs.

## Local parallel evaluation findings —25 November2026
The current lab grader receives question, reference, contract and answer text only; it does not receive retrieved source content or saved citations/verification. Therefore its score measures reference agreement, not independent source truth. Additional true details absent from a reference may be marked unsupported. Q04/Q20 also have real completeness gaps; this limitation is not grounds to declare them passing. Keep the current rubric unchanged during this goal so scores remain comparable. A future evidence-aware grader should use bounded server-resolved source content with checked claims, version its method, distinguish reconstructed evidence and preserve earlier scores. Never trust a client-submitted verified flag alone.

Public grader context now has an explicit method version (public-source-context-v1). It reconstructs only registered public captures with byte hashes and bounded transport, preserves prior judge history, and distinguishes additional supported facts from facts absent from the reference. Rubric criteria/weights and question references remain unchanged. Account grading remains reference-only. This is not a claim of original retrieval provenance or live policy verification.
