# Stitch prompts for every CRM page

Issue #58 uses the same private project and Smart Campus design system documented in `STITCH_ALL_PAGES_EVIDENCE.md`.

## Shared instruction sent with every page

Redesign one authenticated desktop screen for STU Nexus, Shu-Te University's all-in-one school CRM/SIS/LMS. Preserve every named function and make every required action visibly discoverable, but independently choose the information architecture, hierarchy, component composition, density, and visual solution. Never design, reference, reroute, or modify the public landing page. Use realistic institutional data and represent loading, empty, error, success, disabled, focus, and permission-aware states. Controls need visible text or accessible names and 44px targets.
