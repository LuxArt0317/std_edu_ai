# Captured public STU assets

These images and SVGs support the dated university interface copy. `provenance.json` records each public source URL, local file, SHA-256 checksum and byte count. The School Affairs login carousel uses `stu0.jpg` through `stu15.jpg` from the official public ePortal login page, captured on November 3, 2026. Two source URLs currently serve identical image bytes; both URLs remain mapped to preserve the original sequence.

These are local, fixed copies. The site does not request images from the official service at runtime or claim to be the university's official login.
