# Captured public STU assets

These images and SVGs support the dated university interface copy. `provenance.json` records each public source URL, local file, SHA-256 checksum and byte count. The School Affairs login carousel uses `stu0.jpg` through `stu15.jpg` from the official public ePortal login page, captured on November 3, 2026. Two source URLs currently serve identical image bytes; both URLs remain mapped to preserve the original sequence.

These are local, fixed copies. The site does not request images from the official service at runtime or claim to be the university's official login.

On November12,2026, `course-catalog-heading.jpg` was captured from the observed public course-query heading and `housing-logo.png` from the observed room-history logo. Their exact source URLs, hashes and lengths are recorded per asset in `provenance.json`. No private account screenshot or personal record is bundled.

`pending-fees-banner.svg` is the observed public Student Fees logo, captured on November12,2026; its original URL, checksum and length are in the provenance manifest. No authenticated student rows are published in this directory.

`dorm-conduct-logo.png` and `dorm-conduct-notice.png` are the observed public dormitory notice assets. `dorm-conduct-assets.json` records source URLs, MIME types, dimensions and hashes without private event-message URLs or identities.

The `curriculum/` directory holds the university’s public curriculum header and PDF icons. Origin and checksums are recorded in the [curriculum QA guide](../../docs/qa/CURRICULUM_PLANS.md).

The `curriculum-map/` directory contains source logo, header rules, introductory illustration, relationship diagram and navigation button images captured from [Curriculum Mapping](https://info.stu.edu.tw/ACA/student/CM/cm.asp).

The `interdisciplinary/` directory contains the captured program-directory logo and 30 public PDFs. See [provenance](interdisciplinary/README.md).
