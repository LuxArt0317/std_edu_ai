# Public source projections

`ipiac115.json` contains text extracted from the public 37-page 115-entry IPIAC draft, with original URL, capture date, source-PDF checksum and physical-page locators. It contains no expected FAQ answer or private account data. Refresh through `scripts/import-ipiac-source.mjs`; draft year/amount conflicts still require clarification.

`accounting115Fees.json` is the seven-page, checksum-verified Accounting PDF text; refresh with `scripts/import-accounting-source.mjs`. `paymentNotice.json` is the checksum-verified captured registration-payment notice, not the inaccessible exact payment-method page; refresh with `scripts/import-payment-source.mjs`. Historical notice dates remain scoped to their published semester.

`calendarDownloads.json` is generated by `scripts/import-calendar-source.mjs` from the registered Academic Affairs capture. Each calendar PDF is checked for its PDF signature and hashed. The record describes editions and destinations, not event dates or personal assignment deadlines.

`calendarText.json` is derived from registered calendar PDF bytes by `scripts/import-calendar-text.mjs`. It retains the checksum, original pages, derived event rows and page locators. The115 English edition has supported bullet markers; the114 edition is explicitly skipped by this event parser rather than guessed. It is a dated public calendar, not a live event feed or personal graduation record.

`housingPolicy.json` preserves compact sections from two checksum-verified public price/application pages. `wirelessGuide.json` preserves public wireless/device-source text (including tab/div content missed by generic paragraph extraction), source-derived SSIDs and contact fields, and whether a dorm-registration capture exists. These are source projections, not evaluation answers, account values or an active registration service.
